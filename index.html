$ glassy

A small terminal emulator that draws on the GPU and otherwise stays out of the way. Written in Rust on wgpu and alacritty_terminal. macOS and Linux.

install read the README latest release

why

idle
On-demand rendering. With nothing changing on screen, glassy issues no frames and uses no CPU.
redraw
Damage-based. Only cells that changed are rasterised and uploaded.
size
About 11 MB for the stripped release binary (one manual measurement; see benchmarks).
power
Picks the integrated GPU by default. GLASSY_GPU=high overrides it.
graphics
Inline images through the kitty graphics protocol and sixel.
text
Truecolor, colour emoji, CJK fallback, opt-in ligatures, curly and coloured underlines.
chrome
Tabs, split panes, command palette, regex search, a live settings overlay and 60 built-in themes.

install

macOS app + CLI

brew install --cask alliecatowo/tap/glassy

CLI only (macOS, Linux)

brew install alliecatowo/tap/glassy

The macOS app is ad-hoc signed, not notarized. The cask clears the quarantine flag for you.

any Linux or macOS, no sudo

curl -fsSL https://raw.githubusercontent.com/alliecatowo/glassy/main/scripts/install.sh | bash

Downloads the latest release binary, verifies its SHA-256 checksum and installs to ~/.local/bin.

Debian, Ubuntu (signed repo)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://alliecatowo.github.io/glassy/deb/glassy-archive-keyring.asc | sudo tee /etc/apt/keyrings/glassy.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/glassy.asc] https://alliecatowo.github.io/glassy/deb/ ./" | sudo tee /etc/apt/sources.list.d/glassy.list >/dev/null
sudo apt update && sudo apt install glassy

Fedora 41+, RHEL (signed repo)

sudo dnf config-manager addrepo --from-repofile=https://alliecatowo.github.io/glassy/rpm/glassy.repo
sudo dnf install glassy

Older dnf4: sudo dnf config-manager --add-repo https://alliecatowo.github.io/glassy/rpm/glassy.repo. openSUSE: zypper addrepo with the same URL.
